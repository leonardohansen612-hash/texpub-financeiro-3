TEX PUB FINANCEIRO 3.1 — INSTRUÇÕES

1. No Supabase: SQL Editor > cole e execute supabase_schema.sql.
2. Authentication > Providers > Email: desative cadastro público (Allow new users to sign up).
3. Authentication > Users > Add user: crie o usuário administrador com e-mail e senha fortes.
4. Project Settings > API: copie Project URL e chave pública anon/publishable para config.js.
   NUNCA use service_role/secret.
5. No GitHub: substitua index.html e adicione config.js e cloud.js na raiz do repositório.
   NÃO envie backup_inicial_privado.json ao GitHub. NÃO envie planilhas ou extratos.
6. Aguarde Vercel atualizar. Acesse o site e entre com o usuário criado.
7. Em Dados e backup > Restaurar backup, selecione backup_inicial_privado.json no seu computador.
   IMPORTANTE: faça isso apenas uma vez, pois substitui o conteúdo atual do banco.
8. Confira os totais e teste um lançamento de R$ 1, depois apague-o.

LIMITAÇÕES DESTA PRIMEIRA INTEGRAÇÃO
- Os dados são armazenados em um documento JSON por usuário (não há compartilhamento entre contas).
- Edições simultâneas em abas/dispositivos podem sobrescrever alterações (última gravação vence).
- Sem conciliação bancária automática, trilha de auditoria ou DRE revisado.
- Não use como única fonte contábil/financeira até conciliar a migração.
- A chave pública pode estar no frontend; a proteção real vem de login + políticas RLS.
- Faça backups frequentes. Para operação multiusuário, próxima versão deve normalizar tabelas e usar operações transacionais.
